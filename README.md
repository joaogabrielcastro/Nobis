# 👥 UserList - Lista de Usuários

Este é um projeto simples feito com React que mostra uma lista de usuários vinda de uma API pública. Você pode buscar usuários pelo nome e ver mais detalhes clicando em cada um deles.

## 🚀 O que dá pra fazer aqui

- Ver uma lista de usuários (nome + e-mail)
- Buscar usuários digitando o nome
- Clicar em um usuário e ver mais informações como telefone, site, cidade e empresa

## 🧰 O que eu usei

- **React** com hooks (`useState`, `useEffect`)
- **Fetch API** para pegar os dados da API
- **CSS** simples pra deixar a interface mais bonita
- API pública: [JSONPlaceholder](https://jsonplaceholder.typicode.com/users)

## ▶️ Como rodar o projeto

Você precisa ter o **Node.js** instalado.

Depois, é só seguir esses passos no terminal:

```bash
# Clonar o projeto
git clone https://github.com/seu-usuario/userlist.git

# Entrar na pasta
cd userlist

# Instalar as dependências
npm install

# Rodar o projeto
npm start
